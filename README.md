# Wordwell English Flashcards

A browser-based app for learning English vocabulary with Vietnamese prompts, English examples, daily goals, and spaced reviews.

## Use the app

Open [Wordwell](https://nhule0502.github.io/wordwell-english-flashcards/). Add cards from **Add vocabulary** and study due cards from **Study today**.

To sync cards and study history across devices, select **Sign in to sync** and create an account. Use the same account on each device. See [SYNC_SETUP.md](SYNC_SETUP.md) for details.

Without signing in, cards are stored locally in the current browser. The app also works without cloud sync.

## Project files

- `index.html` contains the app.
- `supabase-schema.sql` defines the flashcards table and user-scoped row-level security.
- `SYNC_SETUP.md` explains cross-device sync and the configured project.
